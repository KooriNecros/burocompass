Il Problema

Burocrazia inaccessibile

🗣️

Barriera linguistica

Il linguaggio burocratico italiano è opaco anche per gli italofoni. Per gli stranieri è invalicabile senza supporto.

🏛️

Frammentazione degli enti

Comune, Questura, Prefettura, INPS, ASL: ogni pratica porta a un ente diverso con regole diverse.

🔄

Circolo vizioso del digitale

Serve SPID per accedere ai servizi, ma per ottenere SPID servono documenti che richiedono altri servizi.

🧩

Dipendenza da intermediari

Chi non ce la fa si affida a patronati o conoscenti, restando vulnerabile alla prossima pratica.

La Soluzione

Come funziona

💬

Chat multilingue

Risponde nella lingua dell'utente. Auto-detect automatico. Nessun selettore da scegliere.

📋

Wizard guidato

Flow step-by-step per il permesso di soggiorno. Checklist documenti personalizzata per situazione.

👤

Profilo adattivo

L'agente apprende dalla conversazione e aggiorna il profilo utente in automatico, senza chiederlo.

💾

Zero server esterni

Tutto gira in locale. Profilo e storico salvati in localStorage. Nessun account richiesto.

🎯

Linguaggio semplice

Niente gergo burocratico. Passi numerati. Uffici indicati chiaramente per ogni procedura.

📱

Mobile first

Ottimizzato per smartphone. Layout adattivo con tab per wizard e chat separati.

Architettura

Design agentico

UTENTE → Chat Interface → BuroCompass Agent (Claude Sonnet)

BuroCompass Agent
  ├─ System prompt base (ruolo + 14 aree di competenza)
  ├─ Profilo utente iniettato dinamicamente a ogni chiamata
  ├─ Risponde nella lingua dell'utente (auto-detect)
  └─ Emette <!--PROFILE_UPDATE:{...}--> quando apprende nuove info

Route Handler (Next.js API)
  ├─ Parsa il blocco PROFILE_UPDATE con regex
  ├─ Rimuove il blocco dal testo visibile all'utente
  └─ Ritorna { message, profileUpdate? }

localStorage ← profilo strutturato + storico (max 10 msg)

Agenti · Skills · Workflow

Elementi agentici

agent

BuroCompassAgent

Agente principale in api/chat/route.ts. Claude Sonnet, multilingue, 14 aree di competenza. Emette blocchi PROFILE_UPDATE nascosti per aggiornare il profilo senza interrompere la chat.

sub-agent

user-simulator

QA automatizzato in Claude Code. Simula 7 personas in 7 lingue, esegue 7 turni di conversazione, apre issue GitHub in automatico a ogni deviazione rilevata dal design contract.

sub-agent

test-and-commit

CI/CD locale in Claude Code. Invocato dopo ogni modifica al codice: esegue tsc --noEmit → npm run build → git commit → git push. Blocca il push se i check falliscono.

workflow

Profile Update

Flusso silenzioso per l'aggiornamento del profilo utente. Il modello emette JSON in commento HTML; il route handler lo estrae, lo rimuove dal testo, lo invia al client per il merge in localStorage.

workflow

Test → Commit → Push

Pipeline di qualità: type-check + build obbligatori prima di ogni push. Invocabile come sub-agent Claude Code o come script PowerShell standalone (agents/test-and-commit.ps1).

skill

grilling

Intervista relentless per stress-testare decisioni architetturali. Esplora un design tree a round fino a frontiera vuota. Usata nella fase di progettazione per definire le scelte chiave di BuroCompass.

Processo Progettuale · AI + Umano

Prima le decisioni, poi il codice

skill · /grill-me

Intervista relentless a round

La skill mappa tutte le decisioni aperte del design (il "frontier"), propone opzioni numerate con raccomandazione, e aspetta la scelta umana. Il ciclo si ripete fino a frontier vuota. Zero codice finché non è tutto deciso.

2 round · 12 decisioni

Processo in due fasi

Round 1 (Q1–Q8): interaction model, lingua, persistenza, profilo, wizard, onboarding, storico, PROFILE_UPDATE.
Round 2 (Q9–Q12): layout wizard+chat, campi familiari, trigger wizard, feedback visivo.

principio chiave

AI propone · Umano decide

In 3 casi su 12 (Q1, Q8, Q10) il team ha raffinato o esteso la proposta AI invece di accettarla passivamente. Il documento design-decisions.md è diventato direttamente il piano di implementazione.

Roadmap

Prossime implementazioni

📄

Profilo da scansione documento

Definizione automatica del profilo utente tramite scansione di un documento del paese di origine: i dati anagrafici popolano l'onboarding senza inserimento manuale.

🧭

Nuovi workflow guidati

Estensione oltre il permesso di soggiorno: nuovi flussi wizard per altre pratiche (codice fiscale, SPID, iscrizione SSN, residenza) con checklist dedicate.

📱

Diffusione web + APP

Distribuzione dell'applicazione sia in formato web responsive, sia come app nativa mobile, per raggiungere gli utenti sul canale a loro più accessibile.

🎙️

Input vocale

Inserimento dati tramite prompt vocali: abbatte la barriera della digitazione per utenti con bassa digital literacy o difficoltà con la tastiera.
