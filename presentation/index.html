BuroCompass

L'assistente digitale per stranieri nella burocrazia italiana

Francesco Giovo & Manuel Marseglia — Hackathon 2026

Il Problema

🗣️

Barriera linguistica

Il linguaggio burocratico italiano è opaco anche per gli italofoni. Per gli stranieri è invalicabile senza supporto.

🏛️

Frammentazione degli enti

Comune, Questura, Prefettura, INPS, ASL: ogni pratica porta a un ente diverso con regole diverse.

🔄

Circolo vizioso del digitale

Serve SPID per accedere ai servizi, ma per ottenere SPID servono documenti che richiedono altri servizi.

🧩

Dipendenza da intermediari

Chi non ce la fa si affida a patronati o conoscenti, restando vulnerabile alla prossima pratica.

La Soluzione

💬

Chat multilingue

Risponde nella lingua dell'utente. Auto-detect automatico. Nessun selettore.

📋

Wizard guidato

Flow step-by-step per il permesso di soggiorno. Checklist documenti personalizzata.

👤

Profilo adattivo

L'agente apprende dalla conversazione e aggiorna il profilo utente in automatico.

💾

Zero server esterni

Tutto gira in locale. Profilo e storico salvati in localStorage.

🎯

Linguaggio semplice

Niente gergo burocratico. Passi numerati. Uffici indicati per ogni procedura.

📱

Mobile first

Ottimizzato per smartphone. Layout adattivo con tab per wizard e chat.

Architettura Agentica

UTENTE → Chat Interface → BuroCompass Agent (Claude Sonnet)

BuroCompass Agent
├─ System prompt base (ruolo + competenze)
├─ Profilo utente iniettato dinamicamente
├─ Risposta in lingua dell'utente
└─ Emette <!--PROFILE_UPDATE:{...}--> se apprende info nuove

Route Handler (Next.js API)
├─ Parsa il blocco PROFILE_UPDATE dalla risposta
├─ Rimuove il blocco dal testo visibile
└─ Ritorna { message, profileUpdate? }

localStorage ← profilo + storico (max 10 msg)
